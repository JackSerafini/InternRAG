# Initial RAG Prototype

This directory contains notebooks, dockerfiles, and kubernetes configuration files from the initial RAG implementation, which used a custom indexing and retrieval pipeline.

The project has since evolved into a retrieval system that combines semantic search, metadata filtering, and an LLM for query processing.

These notebooks are retained as a reference for potentially reusing the original indexing approach in future, general-purpose RAG projects.

They are not part of the current production pipeline.
